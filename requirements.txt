# Dependencias de Laboratorios CRUB.
#
# Estos pines son los que instala el despliegue: deploy.sh arma un venv nuevo
# con `pip install -r requirements.txt` en cada publicación, así que esto es lo
# que corre en producción. Todos se resuelven en PyPI (verificado con
# `pip download --no-deps -r requirements.txt`).
#
# OJO con el venv/ de desarrollo: puede quedar viejo y no lo avisa nadie. En una
# auditoría se lo encontró varias versiones atrás del archivo (Flask 2.3.3
# contra 3.0.3, Werkzeug 2.3.7 contra 3.1.3, pandas 2.2.3 contra 3.0.1) y además
# con dos docenas de paquetes que el código no importa, restos de etapas
# anteriores. Si el venv local no coincide, se está probando otra cosa que la
# que se despliega: rehacerlo desde cero en vez de parchearlo.
#
#     rm -rf venv && python -m venv venv && venv/bin/pip install -r requirements.txt
#
# Al actualizar una versión acá, rehacer también el entorno local.
